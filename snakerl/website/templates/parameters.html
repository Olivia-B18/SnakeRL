How To Train an RL Agent


Untrained Agent Discussion

As you saw on the previous page, untrained agents are very bad at playing Snake. They may get lucky and eat the apple once or twice, but generally, they do the wrong thing (i.e. spin in a circle, crash into the wall, crash into themselves, etc.) because they have not yet learned how to play the game. Let's learn how about how we can improve this performance and teach the agent how to play Snake.

Use the "next" and "previous" buttons below to read about how to train an RL agent to play Snake. The "back" button will take you back to the last page, as usual.

Markov Decision Processes

RL agents learn by taking actions, or steps, in small worlds called environments. In our case, the agent's environment is the game Snake. At a high level, training is typically done using an environment called a Markov Decision Process (MDP). This just means that the agent learns through a series of states, actions, and rewards.

{% raw %}

A state is where your RL agent will be in the environment and what it knows, such as being on a normal tile, being on the same tile as the apple, or crashing into the wall. The agent will take actions, such as moving the snake up, down, left, or right. Rewards encourage the agent to continue doing certain actions while discouraging others. The reward is determined by the progression from the current state \( s \) by taking an action \( a \), and entering the next state \( s' \), often written as a reward function:

\[R(s, a, s') \] {% endraw %}

What are Q-values?

When the agent learns, it has no idea what actions lead to what rewards. As it takes actions, it approximates how good actions are by tracking Q-values. In a sentence, a Q-value is saying, "if the agent is in state \( s \) and takes action \( a \), and then acts optimally, always exploiting its best known actions thereafter, what is its predicted reward in the end?"

Q-values are like navigating a maze. Mazes have different paths you can take. Some cross, some lead to crossroads, others to dead ends, and there are many paths that lead to the end of the maze. A Q-value denotes the value for taking an action in a given state and acting optimally thereafter. For example, the value for a path through the maze may be low because taking a circuitous route that detours and skirts a dead end is less effective than taking a more direct route.

The Bellman Equation

The Bellman Equation gives two key formulas to update a Q-value:

{% raw %}

Formula 1: Calculate the sample. After taking action \( a \), the agent gets reward \( r \) and lands in state \( s' \). It adds that reward to the best Q-value it can get from the new state:

\[ \text{sample} = \underbrace{r}_{\text{reward now}} + [ \underbrace{\gamma}_{\text{discount factor}} \times \underbrace{\max_{a'} Q(s', a')}_{\text{best Q-value from s'}} ] \]

Formula 2: Update the Q-value. The agent doesn't throw away its old guess. It nudges its old Q-value a little bit toward the sample:

\[ \underbrace{Q(s, a)}_{\text{new guess}} \leftarrow \underbrace{Q(s, a)}_{\text{old guess}} + [ \underbrace{\alpha}_{\text{learning rate}} \times \underbrace{\left( \text{sample} - Q(s, a) \right)}_{\text{how wrong the old guess was}} ] \] {% endraw %}

Hyperparameters

So how do you use the Bellman Equation to train the agent? There are two things to focus on tweaking: the settings for the agent itself and the settings for its environment. These settings are called hyperparameters.

Agent Hyperparameters

1. The learning rate \( \alpha \) (alpha) affects how much the agent learns from new information at each step. It is usually a small value like 0.001 to ensure that the agent learns at a slow and steady pace. Bigger values like 0.1 cause the agent to change Q-values more drastically and potentially destabilize learning.

2. The discount factor \( \gamma \) (gamma) controls how much the agent cares about future rewards over immediate rewards. It is usually a large value like 0.99. This means that if it takes 3 actions to earn a 10-point apple, then the final reward will be {% raw %} 10 * 0.99^(3-1) = 9.801 {% endraw %}. As you can see, the discount factor doesn't reduce the reward too much, but it does encourage the agent to find its goal sooner than later.

3. The exploration rate \( \epsilon \) (epsilon) determines how much the agent prioritizes exploration over exploitation. It is usually set to an initial value like 0.80 and then decays over time. This means that for the first action, the agent has an 80% chance of choosing an action randomly (exploration) and a 20% chance of exploiting its best known policy (or strategy) by taking the best action it knows to so far. This initial 0.80 may reduce to 0.79 for the second action, meaning that by eightieth action, the agent will have a 100% chance of choosing to exploit. Typically, the exploration rate is very high in the beginning of training to encourage trying out new actions, and then it decays over time so that the agent will prioritize earning rewards.

Environment Hyperparameters

A core concept of RL is setting up a good environment for the agent to learn in. This means defining a reward function \( R \) to determine how the agent earns rewards. Consider whether the snake agent should earn positive, negative, or zero rewards for the following:

  • How many points does the agent earn when it eats an apple?
  • How many points does the agent earn when it crashes into itself or the wall?
  • How many points does the agent earn just for staying alive?
