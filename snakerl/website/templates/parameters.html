How To Train an RL Agent

Markov Decision Processes

RL agents learn by taking actions, or steps, in small worlds called environments. In our case, the agent's environment is the game Snake. At a high level, training is typically done using an environment called a Markov Decision Process (MDP). This just means that the agent learns through a series of states, actions, and rewards.

{% raw %}

A state is where your RL agent will be in the environment and what it knows, such as being on a normal tile, being on the same tile as the apple, or crashing into the wall. The agent will take actions, such as moving the snake up, down, left, or right. Rewards encourage the agent to continue doing certain actions while discouraging others. The reward is determined by the progression from the current state \( s \) by taking an action \( a \), and entering the next state \( s' \), often written as a reward function:

\[R(s, a, s') \] {% endraw %}

The Bellman Equation

When the agent learns, it has no idea what actions lead to what rewards, so it approximates the values for the actual rewards. These approximations are called Q-values. The Bellman Equation gives two key formulas to update a Q-value:

{% raw %}

Formula 1: Calculate the sample. After taking action \( a \), the agent gets reward \( r \) and lands in state \( s' \). It adds that reward to the best Q-value it can get from the new state:

\[ \text{sample} = \underbrace{r}_{\text{reward now}} + [ \underbrace{\gamma}_{\text{discount factor}} \times \underbrace{\max_{a'} Q(s', a')}_{\text{best Q-value from s'}} ] \]

Formula 2: Update the Q-value. The agent doesn't throw away its old guess. It nudges its old Q-value a little bit toward the sample:

\[ \underbrace{Q(s, a)}_{\text{new guess}} \leftarrow \underbrace{Q(s, a)}_{\text{old guess}} + [ \underbrace{\alpha}_{\text{learning rate}} \times \underbrace{\left( \text{sample} - Q(s, a) \right)}_{\text{how wrong the old guess was}} ] \]

In a sentence, a Q-value is saying, "if the agent is in state \( s \) and takes action \( a \), and then acts optimally, always exploiting its best known actions thereafter, what is my predicted reward in the end?"

{% endraw %}

Parameters of the Agent and the Environment

So how do you use this formula to train the agent? There are two things to focus on tweaking: the settings for the agent itself and the settings for its environment.

The Agent

1. The learning rate \( \alpha \) affects how much the agent learns from new information at each step. It is usually a small value like 0.001, so you can see that in the second formula, it affects how much we want the agent to nudge its Q-values up or down.

2. The discount factor \( \gamma \) controls how much the agent cares about future rewards over immediate rewards. It is usually around 0.99, so when it is compounded over multiple steps, this greatly reduces the final reward. Essentially, it encourages the agent to complete its task sooner than later.

3. The exploration rate \( \epsilon \) determines how much the agent prioritizes exploration over exploitation. According to some probability, like 0.80, there is a chance that the agent will either explore new actions randomly, or it will exploit its best known policy by only taking the best actions it knows so far. Typically, the exploration rate is very high in the beginning of training to encourage trying out new actions, and then it decays over time so that the agent will prioritize earning rewards.

The Environment

A core concept of RL is setting up a good environment for the agent to learn in. This means defining a reward function \( R \) to determine how the agent earns rewards. Consider whether the snake agent should earn positive, negative, or zero rewards for the following:

  • How many points does the agent earn when it eats an apple?
  • How many points does the agent earn when it crashes into itself or the wall?
  • How many points does the agent earn just for staying alive?
