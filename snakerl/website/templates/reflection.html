Reflection

The goal of this project is to teach its audience the foundations of RL in an easy to understand way. We hope you enjoyed the journey.

If you'd like to play again, select any of the buttons below to return to a previous page. When you go through the training and evaluation process, consider?

  • What do you think core of reinforcement learning is?
  • Theoretically, can an agent designed to play Snake be taught to play a different game like Blackjack?
  • How did your agent perform? If it didn't do well, what settings might help it earn more points?
  • Try training multiple times using the same settings. Sometimes, agents are unlucky with some runs but are lucky with others because of the randomization.
  • What do you think the snake knows or should know about its environment?
  • What do different values for the learning rate, discount factor, exploration rate, and reward function do?
